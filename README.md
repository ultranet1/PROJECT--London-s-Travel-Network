# Exploring London’s Travel Network 🚇🇬🇧

This project analyzes London's public transport system using SQL and Python, focusing on journey volumes by transport type. The analysis is based on Transport for London (TfL) data.

## 📌 Project Overview
- **Goal:** Explore and analyze London's public transport usage trends.
- **Role:** Data Engineer  
- **Skills:** SQL queries, data cleaning, data visualization, data storytelling.
- **Tools:** Python, Jupyter Notebook, Pandas, Matplotlib, SQL.

## 📂 Files
- **notebook.ipynb** — Main analysis and SQL tasks.
- **tfl_journeys_final.csv** — Public transport journey dataset.
- **london.jpg** — Image of London (Tower Bridge).
- **tube.jpg** — Image of the London Underground.
- **.gitignore** — Files to be ignored by Git.

## 📊 Dataset
The dataset contains journey volumes for different modes of transport in London, including:
- Underground 🚇
- Overground 🚆
- Buses 🚌
- Trams 🚋
- River Services ⛴️
- Cable Car 🚡

Source: [Transport for London (TfL) Open Data](https://tfl.gov.uk/info-for/open-data-users/)

## 📈 Key Insights
- Most popular transport types in London.
- Yearly trends in public transport usage.
- Seasonal patterns and peak usage times.

## 🚀 How to Run
1. Clone this repository:
   ```bash
   git clone https://github.com/ultranet1/Exploring-Londons-Travel-Network.git
   ```
2. Open `notebook.ipynb` in Jupyter Notebook or Google Colab.
3. Run all cells to reproduce the analysis.
